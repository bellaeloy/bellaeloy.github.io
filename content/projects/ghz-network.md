Horizontal data governance needs a shared picture of who talks to whom. Text
alone does not carry that picture.

This site draws the GHZ network as a graph. Each node is a social agent. Each
edge is a relation. A reader can follow one agent and see every group it joins.

The graph reads from a single data file, so a group can update the network
without a change to the code.
