This is where the data side of my work starts. The course pairs Python with
public data from Brazilian cities.

The notebooks cover the full path: fetch an open dataset, clean it, join it to a
boundary file and draw the map. The exercises use budget data, school data and
bus route data.

The skills carried straight into [Urban Void Atlas](../urban-void-atlas/), which
runs the same pipeline at city scale.
